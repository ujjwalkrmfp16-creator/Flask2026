# Flask TODO Application 📝

A simple and responsive TODO web application built using Flask and SQLite. 
This project demonstrates CRUD operations, database integration, HTML templates, and deployment of a Flask application.

## ✨ Features

- ➕ Add new TODOs
- 📋 View all TODOs
- ✏️ Update TODOs
- 🗑️ Delete TODOs
- 🕒 Display TODO creation time
- 📱 Responsive user interface
- ☁️ Deployed online using Render
